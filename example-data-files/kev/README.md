# Locate and save the master KEV Data file

* go to https://github.com/cisagov/kev-data/blob/develop/ or the staging directory in GitHub
* download the `known_exploited_vulnerabilities.json` file
* put in this directory
* run the different `/scripts/patch-vulnerability/*.py` scripts to use the KEV data

Update the KEV data as required and re-run for the latest results.
