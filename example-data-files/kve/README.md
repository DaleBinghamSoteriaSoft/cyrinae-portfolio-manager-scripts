# Locate and save the master KVE CSV file

* go to https://github.com/cisagov/kev-data/blob/develop/ or the staging directory in GitHub
* download the `known_exploited_vulnerabilities.csv` file
* put in this directory
* run the different `/scripts/patch-vulnerability/*.py` scripts to use the KVE data


Update the KVE data as required and re-run for the latest results.
